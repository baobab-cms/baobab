# Baobab

Baobab CMS is a modular, open-source CMS built on Laravel — designed for developers and agencies who need real typed content, not another EAV-based content model.

This repository is the **application skeleton**: the starting point for a new Baobab site, installed via `composer create-project baobab/baobab`.

## Status

🚧 **Pre-release.** This repository currently reserves the `baobab/baobab` package name on Packagist ahead of the first public release. `composer create-project baobab/baobab` is **not yet functional** — the CMS core (`baobab/core`) and default theme (`baobab/default-theme`) this skeleton depends on haven't been published yet.

Watch this repository or check back for the v1 release announcement.
